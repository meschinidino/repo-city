# Repo City

Shared agent rules for this repo live in [AGENTS.md](AGENTS.md): what to read first, where to start, gate order, honesty rules, design rules, docs sync and git. Follow them. Start with [notes/working-notes.md](notes/working-notes.md).

## Design System
Read DESIGN.md before visual or UI work: it defines the fonts, colors, spacing, and
aesthetic direction. Ask the user before departing from it. When reviewing or QA-ing
UI, flag code that doesn't match DESIGN.md.
