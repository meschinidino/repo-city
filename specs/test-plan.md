## Affected Pages/Routes
- `/` map view — the repo opens as islands (districts) joined by bridges (import roads); buildings typed by what each file does; a bottom command bar with one token per agent and a quest log for session CRUD; report cards that open beside their island
- WebSocket event stream — ship and lit-window state, scaffolding on the building being edited, pennants for test results, reports, failure markers
- Sprite pipeline at load — sheets in `assets/sprites/` keyed, cut, measured and placed; geometry checks run before the map is shown

## Key Interactions to Verify
- Open a TS/JS repo and read three islands unaided on `/`, including what their landmark buildings say (entry point, endpoints, data, shared utility, dead code)
- Create a quest from the command bar on an island, watch the ship arrive and windows light on real file events, read the English report on the island's report card
- Drag a lane between two islands, edit or cancel the confirmation, confirm to start real work; the lane becomes a bridge only after the real import exists
- Accept a finished quest from the report card (merge), handle a conflict, discard a quest
- Pause, resume, stop, and archive quests from the quest log, including archiving a running one

## Edge Cases
- Unparseable files and unresolved imports are counted and shown, never silently skipped on `/`
- Agent stalls, crashes, or emits unmappable events: the ship stays at the island's gate marked location unknown, never docked at an invented building
- Report generation fails: raw events and diff stats with a retry on the card, no polished fake report
- Two quests touch the same file: overlap marker on both islands
- Repo at the stated limit (roughly 2,000 files), 3 concurrent quests; map zoom shows landmarks and a housing mass, not 2,000 buildings
- A sprite sheet is missing, regenerated with drift, or fails a fail-level geometry check: the client says which check failed and does not render a broken map
- An island too small for its buildings with spacing: the layout relaxes spacing and says so; it never overlaps footprints
- Empty states: no quests yet, an island with no landmark files, a repo with one module
