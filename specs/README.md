# Specs

The documentation the planning workflow produced for this project, in repo form. The canonical, skill-maintained copies live under `~/.gstack/projects/meta-hackathon/`; when those change, re-copy them here in the same commit (see [notes/working-notes.md](../notes/working-notes.md#where-the-plan-lives)).

| File | What it is |
|---|---|
| [design.md](design.md) | Approved design doc: problem, premises, approaches considered, recommended approach, committed contracts, the D1–D18 decision ledger, failure modes, implementation tasks T1–T10, and the review report. Status: APPROVED |
| [test-plan.md](test-plan.md) | Test plan: the five E2E journeys, edge cases, and critical paths with their value cards |
| [tasks.jsonl](tasks.jsonl) | Machine-readable subset of the implementation tasks |
| [hackathon-rules.md](hackathon-rules.md) | Meta Global AI Developer Hackathon rules, dates, eligibility, submission requirements, judging rubric, bonus prizes, and the anti-project list |
